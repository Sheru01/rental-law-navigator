    What this does not claim

    • Not that the data is wrong. The published record does not contain the field, which is a different and narrower claim.
    • Not a generalisation past the sample. The ledger describes this evaluated set on one retrieval date.
    • Not that any jurisdiction is negligent. Assessor schemas differ for ordinary historical reasons.
