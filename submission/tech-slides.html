1 · Tech stack

A model reads. Code decides.

Python standard library end to end. No LLM decides whether a rule applies. Playwright gates every push; Vercel serves one self-contained page.

Python throughout. A model extracts structured rules from legal text, the Census geocoder resolves each address, and a deterministic engine decides coverage.

2 · Implementation highlight

Two kinds of silence, never collapsed.

unknown

The rule is operative, but a building fact is absent from the public record. The card names the fact and what would resolve it.

indeterminate

The legal record itself cannot establish the rule is operative. Status is withheld as null, so it can never resolve to "applies".

# engine, three-valued AND over predicates
AND: any false -> false; else any unknown -> unknown; else true

# a withheld projection reaches the UI, it is never silently dropped
"result_state": "indeterminate", "reason_code": "projection_withheld"
A gap in the building record and a gap in the legal record have different fixes, so the engine reports them as different states.
3 · Challenges

Two modules, one disagreement.

The geocoder wrote legal_city. The engine read jurisdiction. Nobody had wired them, because the engine had only ever run against a fixture using the other spelling. Every one of the 500 addresses read "not resolved".

# navigator/engine/run.py
  jur = j.get("jurisdiction")

  # never fall back to postal_city: unresolved stays None

Found only by binding real output instead of fixtures. Fixed with the suite green: 273 passed, 2 skipped.

3 · Limitations, stated on the product

The demo says what it is not.

Not a live model run

Demo rules replay recorded extraction fixtures. A live run needs a key and spend, so the site header says so, in every frame.

Integrity, scoped honestly

The corpus manifest hashes match nothing in the distributed text, so the drawer claims only a locally recorded hash, never validation.

# site header, rendered from the pipeline's own flag
"is_real_extraction": false
→ "Rules replayed from extraction fixtures, not a live model run"

A system whose argument is that it does not overclaim cannot overclaim about itself.

The rules come from replayed fixtures, not a live model run, and the site says so in its header. We did not overclaim about the thing that refuses to overclaim.
4 · Takeaway

Refusing to guess turned out to be the product.

The unknowns were supposed to be the scoring loss. Aggregated, they became a sourced map of what the public record cannot answer.
